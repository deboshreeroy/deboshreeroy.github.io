Experiment Design & Metric Validation

A product experimentation case study: defining success metrics and guardrails, running an A/B analysis, and writing a decision memo that accounts for tradeoffs and risk.

Overview

This project is intentionally written like a real product decision: define the goal, measure safely, decide clearly.

Problem

A feature change improved a short-term engagement metric, but the team was unsure whether it was “real value” or just shifting behavior. The goal was to design an experiment and validate metrics so the decision would hold up.

  • Define a primary metric that reflects the product goal
  • Add guardrails to prevent “winning the metric” at user expense
  • Analyze results with appropriate uncertainty + segmentation

Experiment design

  • Population: eligible active users
  • Randomization: user-level assignment
  • Duration: long enough to capture habit + novelty effects
  • Power: back-of-the-envelope MDE + sample size estimate
  • Risks: interference, seasonality, logging changes

Metrics

  • Primary: activation-to-retention or meaningful usage (not raw clicks)
  • Secondary: session frequency / depth
  • Guardrails: latency, error rate, unsubscribes, user complaints
  • Quality: long-term engagement proxy (week 2+ retention)

Analysis

  • Difference-in-means + confidence intervals
  • Non-parametric check (bootstrap) for robustness
  • Segment cuts (new vs existing, light vs heavy users)
  • Sanity checks for randomization + logging consistency

Key findings

  • Observed lift in primary metric was concentrated in a specific segment (e.g., new users)
  • Guardrails stayed flat → improvement likely not at the expense of reliability
  • Some secondary metrics rose while others didn’t → clarified mechanism of impact

Decision memo

Recommendation: ship to 100% for the segment where impact is meaningful, and run a follow-up test to validate long-term retention effects. Document risks and monitoring thresholds.

  • Ship criteria + monitoring plan
  • Open questions + next experiment
  • Rollback triggers if guardrails move

Where it breaks

  • Metric sensitivity: short-term wins can mask long-term harm
  • Seasonality: experiments spanning holidays can mislead
  • Instrumentation: logging changes can create fake lift

Next steps

  • Holdout group for long-term measurement
  • Define a north star metric aligned to user value
  • Build a reusable experimentation template / notebook
